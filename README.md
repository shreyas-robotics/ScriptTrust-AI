# ScriptTrust-AI

## AI Handwritten Exam Evaluation System

ScriptTrust-AI is an AI-assisted system designed to evaluate handwritten exam answers.

The system reads handwritten answers from images, extracts the written content using handwriting OCR, evaluates the answer against a predefined rubric, suggests a score, provides evidence and feedback, and allows a human examiner to review and finalize the mark.

---

## Key Features

- Handwritten answer image upload
- Handwriting line detection
- Handwritten text recognition using TrOCR
- Semantic answer evaluation
- Rubric-based scoring
- Criterion-level pass/fail evaluation
- Semantic similarity scoring
- Confidence estimation
- Human review recommendation
- Examiner mark override
- Examiner notes
- Final mark confirmation
- PDF evaluation report generation
- Test dataset validation dashboard
